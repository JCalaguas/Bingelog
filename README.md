# BingeLog

BingeLog is a personal tracker for anime and TV shows. It keeps one record of
every show you watch — the current episode, status, rating, and notes — so you
always know where you are and what you thought of it.

> **Live site:** (link)
> **API:** (link)
> **Demo video:** (link)

## What it does

- Add shows to your library, optionally pulling title, cover and episode count
  from the TVMaze metadata API
- Track progress (current episode / total episodes), status, rating and notes
- Browse and filter your library by status

## Built with

React (Vite) and React Router on the front end, Express and PostgreSQL on the
back end.
